怎样在线编辑这套文档

阅读在博客里完成，修改在 GitHub 网页里完成。用 herrluk 账号登录后，提交的修改会保存到仓库，并自动生成新版网页。

改一段讲解，只需三步

  1. 打开章节，点击顶部的“在线编辑本页”。例如哈希章节会打开 学习文档源码/content/01.py。
  2. 用浏览器搜索找到要改的那句话，修改引号里的中文。保留引号、逗号和缩进；文字里需要单引号时可改用中文引号。文件同时保存讲解、例子与代码，并不是网页排版代码。
  3. 点击 Commit changes…，写一句修改说明，提交到 main。到 发布记录 查看本次运行；绿色成功后，刷新博客。

直接编辑：01 哈希查找与集合 →

'summary': '这里是一道题的题意说明。',
'insight': '这里解释为什么会想到这个方法。',

这里提供的是在线源码编辑。网页正文不能像 Word 那样直接点击改字。优先修改短句；如果改到算法代码，自动检查会先执行示例。检查失败时，新版本不会发布，可以从发布记录查看错误并修正。

一次修改多个文件

打开 浏览器编辑器 github.dev，在左侧展开 hot100-150。也可以在 GitHub 仓库页面按英文句号 . 打开。修改后在“源代码管理”中暂存、填写说明并提交推送，发布流程相同。

保存、发布与本地文件的关系

GitHub 中每次提交都有历史记录，可以查看差异、找回旧内容。生成的章节 HTML 是发布结果；以后应修改源码。线上修改不会自动写回电脑里的原始 hot100+150 目录。

本地继续修改时，先同步博客仓库的最新内容，再编辑其中的 hot100-150。避免用旧的本地文件覆盖网页端的新修改。
