和本目录中的算法基础、训练循环、推理 Infra、DPO/GRPO/PPO 内容高度重合，适合作为每章后的手写练习。

为什么值得记录

它填补的是“看懂了”和“能写出来”之间的空白。题目不是只围绕某个训练框架，而是从激活函数、归一化、注意力和位置编码，一直延伸到训练技巧、KV Cache、Paged Attention、FSDP、Reward Model、DPO、GRPO 与 PPO。浏览器内置编辑器，本地评测给出逐项测试反馈，还能在自己尝试之后查看参考实现。

核实到的核心能力

76 道实现题 当前中英文 README 都写明为 76 道，涵盖 14 个方向。
本地即时评测 提交代码后运行测试并显示通过或失败，不依赖 GPU。
完整学习路径 包含 Transformer、训练 GPT、推理与分布式、对齐与推理搜索等路线。
进度与参考实现 记录完成情况和尝试历史，允许在独立完成后对照答案。

建议接入当前 RLHF 学习路线

  1. 先补最小实现能力 Softmax → Linear → RMSNorm → Scaled Dot-Product Attention → Multi-Head Attention。
  2. 再连接训练循环 Cross Entropy → Adam → Gradient Accumulation → Mixed Precision → Activation Checkpointing。
  3. 进入对齐算法 Reward Model → DPO → GRPO → PPO。每完成一道题，就回到本地文档解释输入、输出和训练信号。
  4. 最后补齐 Infra 视角 KV Cache → Top-k Sampling → Paged Attention → Tensor Parallel → FSDP。

使用原则

推荐：先关闭 AI 辅助，限定 30～45 分钟独立完成；如果失败，先读测试错误，再回看当前学习文档；最后才看参考实现。这样才能把它当作“检验理解”的训练场，而不是答案浏览器。

注意：“无需 GPU”不等于无需环境。官方 README 要求 Python 3.11+ 和 Node.js 18+。可选 AI 辅助会使用你配置的兼容 API；不要把真实 API Key 写进公开文档或提交到 Git。
